00准备两样东西

  1. Cloudflare 账号。没有的话去 dash.cloudflare.com/sign-up 用邮箱注册，免费，不用填卡。
  2. Node.js 18 或更新。去 nodejs.org 下载左边那个 LTS 版本，一路下一步装完。

装完 Node 后打开终端（Mac：启动台搜「终端」；Windows：开始菜单搜「PowerShell」），输入 node -v，看到 v18 以上的数字就好了。

01安装

拿到代码

会用 git 的话：

git clone https://github.com/coredump119/lune-share.git my-prompts cd my-prompts

不会用 git：打开 GitHub 仓库，点绿色的 Code → Download ZIP，解压。然后在终端里输入 cd （后面有个空格），把解压出来的文件夹拖进终端窗口，回车。

装依赖

npm install --legacy-peer-deps

大约一分钟。看到 warning 不用管，没有红色的 ERR 就行。

一键配置

npm run setup

它会依次做这些事：

  1. 打开浏览器让你登录 Cloudflare，点 Allow 授权。这一步授权的是你电脑上的命令行工具，不是我，也不是任何第三方。
  2. 问你四个问题。直接回车就是用括号里的默认值。
  3. 在你的账号里建数据库、图片存储，生成两个随机密钥，构建并部署。
[2/8] A few questions Project id, becomes <id>.pages.dev (my-prompts): moon-prompts Site name shown to visitors (Prompt Share): 月光词包 Small line above the name (invite only): by moon Where should images live? 1) KV — free, no credit card, 1 GB total 2) R2 — free up to 10 GB, needs a card on file Choose 1 or 2 (1): 1 … Done. Site https://moon-prompts.pages.dev Admin https://moon-prompts.pages.dev/#/admin Admin key Xk3…（一串随机字符）
Project id 会变成你的网址，只能用小写字母、数字和横线。如果这个名字已经被别人占了，Cloudflare 会自动在后面加几个字符，以最后打印出来的网址为准。
Admin key 就是你的后台密码。它同时保存在项目文件夹的 .dev.vars 文件里。不要发给别人，不要截图发群。

02第一次使用

  1. 打开 你的网址/#/admin，粘贴 Admin key 登录。
  2. 进「邀请码」，填个备注（比如朋友的名字），点生成。明文只显示这一次，马上复制发给对方。库里只存哈希，之后连你自己也看不到。
  3. 进「上传」，把 MJ 原图拖进去，或者直接 ⌘V 粘贴。如果是 MJ 下载的原图，prompt 和参数会自动读出来。
  4. 把你的网址和邀请码发给朋友。对方输入码就能看。
图片会先在你的浏览器里重新编码成 webp 再上传。MJ 写在原图里的完整 prompt 和 --p 不会到服务器。每条 prompt 的 --p 公不公开由你单独决定，默认不公开。

03日常

想做的事在哪里
怀疑某个码被转发了邀请码 → 点那一行看设备和访问记录 → 作废。对方下一次请求就会被踢出去
给码设有效期、限制设备数生成时填天数和设备数
同一个站放好几个词包，不同的人看不同的上传页底部建「集合」，生成邀请码时只勾对应的集合。没放进集合的 prompt 只有「全部」权限的码能看到
让朋友也能投稿生成码时打开「可投稿」。投稿先进「内容 → 待审核」，你通过了才公开
已经在 LUNE 里整理好了LUNE 里导出 .lune.json，后台「导入」选这个文件。文件夹会变成集合
一次处理很多条内容 → 选择 → 批量发布 / 下架 / 置顶 / 删除
备份或者搬家画廊标题下的「导出」，可以导成 .lune.json 或 Word

04修改和更新

改完任何东西之后，在项目文件夹里运行这一条就会重新上线：

npm run deploy
改什么怎么改
站点名字、名字上面的小字用记事本打开 wrangler.toml，改 SITE_NAME 和 SITE_TAGLINE
不想让访客一键导出wrangler.toml 里把 EXPORT_FOR 改成 "admin"
登录保持多少天SESSION_DAYS
背景图替换 public/day.jpg（浅色）和 public/night.jpg（深色），建议宽 2400 像素以内
用自己的域名Cloudflare 后台 → Workers & Pages → 你的项目 → Custom domains

拿到模板的新版本

git pull npm install --legacy-peer-deps npm run db:apply npm run deploy

用 ZIP 下载的话：下载新的 ZIP，把旧文件夹里的 wrangler.toml 和 .dev.vars 两个文件复制进新文件夹，再运行后三条。你的数据在 Cloudflare 上，不在这个文件夹里，不会丢。

换电脑前把 wrangler.toml 和 .dev.vars 备份好。这两个文件是 setup 为你生成的，不会上传到 GitHub。

05免费额度够用吗

服务免费额度大概意味着
Pages Functions每天 10 万次请求一个访客翻一遍约几十次请求
D1 数据库5 GB，每天 500 万行读文字内容永远用不完
KV（默认存图）共 1 GB；每天 1000 次写、10 万次读约 3000 张图；一天最多上传 1000 张；图片会在访客浏览器里缓存一天
R2（可选存图）10 GB需要在 Cloudflare 绑一次卡才能开通

数字以 Cloudflare 官方定价页为准。免费档超额时请求会被拒绝，不会产生费用。只有你主动开通了付费项（比如绑卡后的 R2 超过 10 GB）才会计费。

06常见问题

有没有「粘贴一个 API key 就能用」的网页版，不用装东西？

没有，而且是故意不做的。邀请制要成立，就必须有一段只在服务器上运行、访客碰不到的代码来检查邀请码和保管密钥。如果做成一个公共网页让你粘贴 Cloudflare 的 API key，那这个 key 要么存在我的服务器上（你的账号就交到了别人手里），要么存在访客的浏览器里（任何访客都能拿走）。两种都不安全。

现在的方式是你在自己电脑上登录自己的 Cloudflare，脚本替你把所有步骤跑完。多花几分钟，换来的是整个站从头到尾只属于你。

setup 中途失败了怎么办？

直接再运行一次 npm run setup，它会问你是否覆盖，选 y。已经建好的数据库和存储会被找到并继续使用，不会重复创建。最常见的原因是网络问题，或者浏览器登录那一步没点 Allow。

忘了 Admin key

打开项目文件夹里的 .dev.vars（文件名以点开头，Mac 上按 ⌘⇧. 显示隐藏文件）。如果这个文件也丢了，运行下面这条设一个新的，然后 npm run deploy：

npx wrangler pages secret put ADMIN_SECRET --project-name 你的项目id
我想从 KV 换到 R2

在 Cloudflare 后台开通 R2，运行 npx wrangler r2 bucket create 你的项目id-images，然后在 wrangler.toml 里加上下面这段，再 npm run deploy。KV 那段保留着不要删，旧图片会继续从 KV 读，新图片写进 R2。

[[r2_buckets]] binding = "IMAGES" bucket_name = "你的项目id-images"
访客能看到我的 --p 吗？

只有你在那条 prompt 上打开了「公开 P 值」才能。没打开的话，服务器根本不会把它发给访客的浏览器，导出文件里也不会有。投稿者提交的 --p 永远不会公开。

被人截图或者整包导出怎么办？

能看到就能复制，这一点任何网站都防不住。这个站能做的是让你知道每个码在几台设备上用过、什么时候来过，并且一键作废。不想让访客批量导出的话，把 EXPORT_FOR 设成 "admin"。

Windows 能用吗？

能。命令在 PowerShell 里完全一样。

想删掉整个站

Cloudflare 后台 → Workers & Pages → 删除项目；Storage & Databases 里删除同名的 D1 和 KV。删完就什么都不剩了。
